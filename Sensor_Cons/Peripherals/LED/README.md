# LED Driver for STM32F429

The LED subsystem is split into single-responsibility modules so each can
be tested, replaced, or reused independently.

## Files

| Module | File(s) | Responsibility |
|--------|---------|---------------|
| **LED state** | `led.h` / `led.c` | Drive a GPIO-connected LED on or off. Knows nothing about timing. |
| **Fixed-rate blink** | `led_blink.h` / `led_blink.c` | Toggle an LED at a regular interval. The caller supplies the current time. |
| **Pattern player** | `led_pattern.h` / `led_pattern.c` | Track which frame of a `(state, duration)` table is current. Touches no LED, so one pattern can be rendered as on/off, software PWM, or timer PWM. |
| **Software PWM** | `led_software_pwm.h` / `led_software_pwm.c` | Brightness control via bit-banged PWM. For LEDs on pins with no timer AF (e.g. PG13/PG14 on the F429I-DISC1). |
| **Timer PWM** | `led_pwm_timer.h` / `led_pwm_timer.c` | Brightness control via a hardware timer output compare channel. Same brightness scale as `led_software_pwm`, but the waveform is generated by the timer. |
| **Board pin map** | `board.h` (in `Peripherals/BOARD/`) | Which pins the on-board LEDs are wired to. Import this when you port to a new board. |

## Quick Start — Application 1 (Blink & Heartbeat)

```c
#include "board.h"
#include "led.h"
#include "led_blink.h"
#include "led_software_pwm.h"
#include "sys.h"

LedHandle_t activityLed;
LedBlink_t  activityBlink;
LedPwm_t    breathePwm;

void App_Init(void)
{
    const LedConfig_t config = {
        .port = BOARD_LED_GREEN_PORT,
        .pin  = BOARD_LED_GREEN_PIN,
        .activeLow = BOARD_LED_ACTIVE_LOW
    };
    Led_InitCustom(&activityLed, &config);

    LedBlink_Init(&activityBlink, &activityLed);
    LedPwm_Init(&breathePwm, &activityLed, LED_PWM_DEFAULT_PERIOD_US);

    /* Start blinking at 500 ms period */
    LedBlink_Start(&activityBlink, 500u, HAL_GetTick());
}

void App_Task(void)
{
    uint32_t nowMs = HAL_GetTick();
    uint32_t nowUs = SYS_GetMicros();

    LedBlink_Update(&activityBlink, nowMs);

    /* Or switch to breathing: */
    LedPwm_SetBrightness(&breathePwm, 50u);   /* 50 % */
    LedPwm_Update(&breathePwm, nowUs);
}
```

## API Reference

### LED state (`led.h`)

| Function | Description |
|----------|-------------|
| `Led_Init(handle, port, pin)` | Init with active-high default |
| `Led_InitCustom(handle, config)` | Init with custom config |
| `Led_On(handle)` / `Led_Off(handle)` | Turn on/off |
| `Led_Toggle(handle)` | Flip state |
| `Led_SetState(handle, state)` | Set to LED_ON or LED_OFF |
| `Led_GetState(handle)` | Query current state (const) |
| `Led_IsOn(handle)` | Shorthand for `Led_GetState == LED_ON` (const) |

### Fixed-rate blink (`led_blink.h`)

| Function | Description |
|----------|-------------|
| `LedBlink_Init(blink, led)` | Bind engine to a LED |
| `LedBlink_Start(blink, periodMs, nowMs)` | Start blinking at `periodMs` |
| `LedBlink_Stop(blink)` | Stop blinking and switch the LED off |
| `LedBlink_Update(blink, nowMs)` | Advance engine (call in super-loop) |
| `LedBlink_IsRunning(blink)` | Query whether blinking (const) |

### Software PWM (`led_software_pwm.h`)

| Function | Description |
|----------|-------------|
| `LedPwm_Init(pwm, led, periodUs)` | Bind engine; default period is `LED_PWM_DEFAULT_PERIOD_US` (200 Hz) |
| `LedPwm_Start(pwm, nowUs)` / `LedPwm_Stop(pwm)` | Start/stop modulation |
| `LedPwm_SetBrightness(pwm, 0..100)` | Set duty cycle (clamped) |
| `LedPwm_GetBrightness(pwm)` | Query current duty cycle (const) |
| `LedPwm_Update(pwm, nowUs)` | Drive LED for the current cycle position |
| `LedPwm_Waveform_Smooth(elapsedMs, periodMs)` | Breathing curve: 0..100..0, squared for perceptual linearity |

### Pattern player (`led_pattern.h`)

| Function | Description |
|----------|-------------|
| `LedPattern_Init(pattern, frames, frameCount)` | Bind the player to a static `LedPatternFrame_t` table |
| `LedPattern_Start(pattern, nowMs)` | Reset to the first frame |
| `LedPattern_Update(pattern, nowMs)` | Advance when the current frame has elapsed |
| `LedPattern_GetState(pattern)` | Current frame as `LED_ON` / `LED_OFF` (const) |
| `LedPattern_GetElapsedMs(pattern, nowMs)` | Milliseconds since the current frame began, so the caller can shape brightness across it (const) |

### Timer PWM (`led_pwm_timer.h`)

| Function | Description |
|----------|-------------|
| `LedPwmTimer_Init(pwm, config)` | Enable the timer clock, route the pin to its AF, start the output at 0 % |
| `LedPwmTimer_SetBrightness(pwm, 0..100)` | Set duty cycle (clamped) |

The timer must have output compare channels; TIM6 and TIM7 are rejected. The
carrier frequency is checked against the timer clock at init and rejected if it
cannot be reached at `LED_PWM_TIMER_STEPS` resolution.

## Design Notes

- **Each module has zero opinion about where the clock comes from.** The caller
  passes `HAL_GetTick()` or `SYS_GetMicros()` as a parameter. This keeps the
  modules testable and reusable across different time bases.
- **Board wiring lives in `board.h` only.** The LED modules see generic
  `GPIO_TypeDef*` and `uint16_t pin`.
- **`led_software_pwm` and `led_pwm_timer` are interchangeable output stages.** Both take
  brightness in `0..LED_PWM_MAX_BRIGHTNESS`, so a caller can swap software PWM
  for hardware PWM without changing its own logic. Software PWM resolution
  equals the super-loop period, so blocking work shows up as flicker; the timer
  version is immune.
- **The old `led.c` (v1) documented a `LED_Init`, `LED_Handle_t`, and multi-LED
  pattern API that was removed.** See the Git history if you need it back.
